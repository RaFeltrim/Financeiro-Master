### Como Utilizar o Sistema

#### Para Controlar Entradas:
1. Acesse o sistema via http://localhost:3000
2. Utilize a função de importação para adicionar receitas
3. As entradas serão automaticamente classificadas
4. Monitore o total de entradas na dashboard

#### Para Controlar Saídas:
1. Registre despesas manualmente ou através de importação
2. O sistema categoriza automaticamente as despesas
3. Acompanhe por categoria no painel de controle
4. Receba alertas para gastos acima do planejado

#### Para Gerenciar Contas:
1. Use a seção de contas a pagar para registrar obrigações
2. Defina datas de vencimento e valores
3. Acompanhe o status de pagamento
4. Consulte o histórico de contas pagas
